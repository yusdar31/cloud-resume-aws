Docker Networking Deep Dive: Bridge, Host, dan Overlay Network

Docker hubung container lewat network namespace. Salah pilih driver buat app lambat, security bocor. Paham cara kerja network penting untuk deploy production.

1. Bridge Network (Default)

Bridge network isolasi container dalam satu host. Docker bikin interface virtual docker0. Setiap container dapat IP privat dari subnet bridge.

Saat container jalan di bridge network, Docker buat veth (virtual ethernet) pair. Satu ujung nempel di container (sebagai eth0), ujung lain nempel di bridge docker0 di host. Traffic keluar container lewat NAT. Docker pakai ipt
